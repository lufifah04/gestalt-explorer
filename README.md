# Gestalt Explorer – Understanding Visual Perception

Media pembelajaran interaktif (3D + AR + GenAI) untuk memahami lima prinsip Gestalt: Proximity, Similarity, Closure, Continuity, dan Figure-Ground.

- **Slide 3D interaktif** (Three.js): tiap prinsip punya slide *Kenali* dan *Coba* dengan misi manipulasi.
- **AR Scan kartu** (MindAR): arahkan kamera HP ke kartu Gestalt (folder `cards/`), objek 3D muncul di atas kartu.
- **AI Visual Challenge**: latihan visual dibuat dinamis oleh GenAI (atau mode simulasi bila backend belum diatur).

Buka lewat GitHub Pages: `https://lufifah04.github.io/gestalt-explorer/`
